# Python Finance Dashboard
Instant Responsive Dashboard: We built a fast, incredibly smooth stock tracking app using Streamlit (Python) that updates in the blink of an eye.
Smart Memory Storage: Instead of constantly bothering internet servers for the same data over and over, our app saves the data locally after fetching it once.
Clean Organized Tabs: We organized everything into neat, separate tabs so users can switch between company info, charts, and dividend histories without getting lost.

# AI Integration

Smart Cleaning: The app includes a background algorithm that takes messy, unorganized data from the Yahoo Finance API and irons it out into a clean format.
Bug Fixer: We programmed safety checks to catch and fix common data glitches, ensuring figures like dividend yields and market caps display accurately.
Ready for AI: The backend is built intentionally so we can easily plug in predictive models to spot trends and patterns down the road

# Technology Used/Stack
Frontend: Streamlit—we used this Python framework to create a super-fast, interactive web interface.
Data Source: Yahoo Finance (yfinance) API to pull live and historical stock data from all over the world.
Charts: Plotly Graph Objects to build smooth, interactive candlestick and line charts that look great.
Data Processing: Pandas and NumPy to clean up the backend math and calculate moving averages instantly

# Impact & Benefits
No More Waiting: It cuts down chart loading times to basically zero, making the whole experience feel fluid and responsive.
Easy to Use: It strips away all the confusing technical jargon, making deep stock market analysis easy for anyone to try.
Saves Bandwidth: Because it doesn't download the same data twice, it uses much less internet data and runs smoothly even on slower connections.

# USER ADAPTATION
Time: Special achievements are given for spending time in the app (per visit), which can range from just loading the app to 1 hour.
Visits: More and more visits changes the header by tracking browser cookies, and on the 3rd visit an achievement is triggered, and something mildly fun happens.
Searches: Your recent searches are shown under the main stock/ticker/company search bar, which is saved even when relogging through browser cookies also triggering another achievement for your first search.
